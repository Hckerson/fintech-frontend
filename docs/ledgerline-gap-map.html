Where the docs are out of date

  • P02 is recorded as the starter's login at app/auth/login with open defects; it is rebuilt at app/(auth)/auth/login with H-01 to H-05 and H-16 fixed.
  • Route groups (FD04) are complete: the home page is in (marketing), sign-in in (auth), and an (admin) layout exists.
  • The help center's sections S46 and S47, and S54 (used by the 404 and 500 pages), are built but not marked Built in Phase 5 or Phase 8.
  • Library decision LD1 (charts) is listed as pending, but recharts is now in package.json.

Where the build is missing something the spec asks for

  • Protected routes (FD06): only /dashboard is protected. The other twelve app prefixes, including /admin, are open to signed-out visitors, and the proxy has no admin role check (only the admin layout has one).
  • Register (P03) and Forgot password (P04), which sign-in links to.
  • Privacy and terms links on every public page (S07).
  • The home page's four v1 capabilities (S05), unless OD9 changes the scope.
  • Real sign-up and sign-in from the home page, unless OD10 settles on enquiry only.
